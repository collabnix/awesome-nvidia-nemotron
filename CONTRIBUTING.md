# Contributing to Awesome NVIDIA Nemotron

Thanks for helping keep this list useful and up to date! Contributions of all
sizes are welcome — from fixing a broken link to adding a brand-new model
release.

## How to Contribute

1. **Fork** this repository.
2. **Add your resource** under the most appropriate section of `README.md`
   (Models, Datasets, Tools & Deployment, Tutorials & Starter Kits,
   HuggingFace × Nemotron, Real-World Use Cases, Companies, Videos & Talks,
   Podcasts, Upcoming Events, Papers, or Community).
3. **Keep the existing formatting** — most sections use Markdown tables with
   consistent columns (e.g. `Model | Params | Description | Links`). Match
   the style of the surrounding rows.
4. **Verify your link works** and points to the canonical/official source
   whenever possible (official HuggingFace org, NVIDIA NIM catalog, arXiv,
   official GitHub repo, etc.).
5. **Submit a pull request** with a short description of what you added and
   why it belongs in the list.

## What Belongs Here

- New Nemotron model releases with real HuggingFace / NIM links
- Tutorials, notebooks, or blog posts about Nemotron models
- Tools or integrations that use Nemotron models
- New datasets released by NVIDIA for Nemotron training
- Videos, podcasts, or talks featuring Nemotron
- Companies building production AI with Nemotron (with public references)
- Upcoming events relevant to Nemotron and the NVIDIA AI ecosystem

## What Doesn't Belong Here

- Unofficial or unverified forks/mirrors with no added value
- Dead links or resources that no longer exist
- Content unrelated to NVIDIA Nemotron or the broader NeMo ecosystem
- Duplicate entries already covered elsewhere in the list

## Style Guide

- Use `**Bold**` for resource/model names.
- Keep descriptions concise — one line per entry.
- Sort new rows within a table in a sensible order (e.g. newest first, or
  grouped by size/generation) to match the surrounding entries.
- Prefer official links over third-party aggregators.

## Reporting Issues

If you find a broken link, outdated information, or duplicate entry, please
[open an issue](../../issues) or submit a pull request with the fix.
